# Ячейка как задача

Каждая ячейка в `notebooks/*.py` — функция `@app.cell`, внутри которой первым выражением
стоит объект `Task`. Всё остальное в ячейке — тело задачи.

```python
@app.cell
def _(Task, config):
    t = Task(
        id="deploy-db",
        title="Поднять Postgres на VPS",
        status="todo",          # todo | doing | done | blocked
        priority=2,             # 1 — самый высокий
        kind="shell",           # func | file | shell | note
        owner="agent",          # agent | human
        depends_on=["config"],  # переменные-входы, дублируют DAG marimo для читаемости
        comments=["нужен порт 5432 наружу только через туннель"],
    )
    result = t.run(lambda: run_shell("docker compose up -d db", env=config))
    return (result,)
```

## Поля

| Поле | Смысл |
| --- | --- |
| `id` | уникальный ключ задачи, совпадает с именем выходной переменной по возможности |
| `status` | состояние в туду |
| `kind` | как агент выполняет: вызвать функцию, записать файл, запустить команду, просто заметка |
| `owner` | кто закрывает: локальный агент или человек |
| `depends_on` | явные зависимости (marimo выводит их сам, поле для документации и для не-marimo рантайма) |
| `comments` | свободный лог обсуждения прямо в ячейке |
